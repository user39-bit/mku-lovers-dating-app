### Handling Problem Users

**Inappropriate Behavior:**
1. Receive complaint from user
2. Review evidence/screenshots
3. Issue warning (first time)
4. Suspend account (repeated)
5. Permanent ban (severe violations)

**Fake Profiles:**
1. Notice suspicious account
2. Check photos (reverse image search)
3. Request verification
4. Delete if fake
5. Ban permanently

**Payment Fraud:**
1. User claims they paid but code doesn't match
2. Check M-Pesa statement
3. Ask for proof/screenshot
4. Verify or reject
5. Ban if fraudulent

## 11. Troubleshooting Guide

### Problem: Users can't upload photos
- **Solution:** Check browser storage limits, clear cache, try different browser

### Problem: Data lost after clearing cache
- **Solution:** This is expected, advise users not to clear cache

### Problem: Matches not showing up
- **Solution:** Both users must have paid, both must like each other

### Problem: Messages not sending
- **Solution:** Check internet, refresh page, try different browser

### Problem: M-Pesa payment delays
- **Solution:** Safaricom issue, wait 5-10 minutes, check M-Pesa directly

### Problem: User forgot password
- **Solution:** They must create new account with different email
